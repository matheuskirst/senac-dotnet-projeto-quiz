# Projeto senac-dotnet-projeto-quiz

## Descrição:
Este projeto consiste em um sistema de quiz em formato de jogo, voltado para estudantes que querem aprender conteúdos de informática de forma divertida e interativa.
A ideia é combinar elementos de jogos, como pontuação, níveis, desafios e ranking, com o aprendizado de temas como hardware, software, internet, segurança digital,
sistemas operacionais e produtividade.
## Tecnologias:
- Visual Studio
- Postgresql
- Github
- Figma
